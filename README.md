# Government Audit Intelligence Platform

This project is based on government audit data. It is used to check contractor risk, severity and unusual cases.

## Technologies

Python, Pandas, XGBoost, Scikit-learn, FastAPI and Streamlit.

## Project Work

- Contractor risk analysis
- Severity prediction
- Anomaly detection
- Audit findings analysis
- PDF risk report
- Weekly audit report

## How to Run

FastAPI:

uvicorn main:app --reload

Streamlit:

streamlit run streamlit_app.py
